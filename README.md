# Extraer-Transformar-Cargar

Automatización en Python para la extracción, transformación y carga (ETL) de datos provenientes de distintos formatos — **XML, CSV y JSON** — dejándolos listos para su posterior análisis o para el entrenamiento de modelos de aprendizaje automático.

## Contenido

- `ETL.ipynb` — notebook con el pipeline de extracción, transformación y carga.
- `LICENSE` — MIT License.

## Tecnologías

Python · pandas · ETL · Jupyter Notebook

## Cómo ejecutar

```bash
pip install pandas numpy jupyter
jupyter notebook ETL.ipynb
```
